Welcome to the Clearpth Robotics OutdoorNav GitHub repository! This repository will serve as the starting point to developer looking to create custom applications using our OutdoorNav software and its corresponding Application Programming Interface (API).

Here you can:

* Refer to our [OutdoorNav User Manual](https://docs.clearpathrobotics.com/docs_outdoornav_user_manual/).
* Explore our API endpoints:
  * [Python](python/endpoints/)
  * [C++](cpp/endpoints/)
* Explore our API examples:
  * [Python](python/examples)
  * [C++](cpp/examples/)
* Get help or report API issues by using the [Issues](https://github.com/cpr-application/clearpath_outdoornav/issues) tab.
* Participate in [Discussions](https://github.com/clearpathrobotics/CPR-OutdoorNav/discussions):
    * Provide [product feedback](https://github.com/clearpathrobotics/CPR-OutdoorNav/discussions/categories/product-feedback).
    * Check for [Announcements](https://github.com/clearpathrobotics/CPR-OutdoorNav/discussions/categories/announcements) from CPR, such as new releases.

## API Endpoints

The API endpoints and examples on how to use them are available in both [Python](python/endpoints/) and [C++](cpp/endpoints/). They provide an outline on how to get started with the API. Explore the [README](python/README.md) in the for instructions on how to build and run the various endpoint examples.

## API Examples

The API examples available in this repository demonstrate some of the ways in which the API can be used to build an application ready for deployment around the OutdoorNav Software. The examples are available in both [Python](python/examples/) and [C++](cpp/examples/), with instructions on how to build and run them available in their respective README files.

## Issues

Feel free to create an issue if you have any problems using the API or questions regarding how to use our Outdoor Navigation software.

To create a new issue:

* Go to the [Issues](https://github.com/clearpathrobotics/CPR-OutdoorNav/issues) tab and select [New Issue](https://github.com/clearpathrobotics/CPR-OutdoorNav/issues/new/choose).
* Choose the appropriate category for your issue and click on the corresponding "Get Started" option.
* Fill in the title and requested information
* Click "Submit new issue".

From there, the issue will be assigned to a member of the CPR team who will respond to the issue. If you are unsure
which category to choose for your issue, choose "General bug report". Where possible, please
complete all the information in the predefined templates to help us resolve your issue as quickly
as possible.
